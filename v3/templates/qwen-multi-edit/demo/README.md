# ComfyUI Demo

Test scripts using `@stable-canvas/comfyui-client` library.

## Setup

```bash
npm install
```

## Test Scripts

### WebSocket Mode (Real-time Progress)

```bash
npx ts-node src/test-client.ts
```

### Polling Mode (No WebSocket)

```bash
npx ts-node src/test-polling.ts
```
